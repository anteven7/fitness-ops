# End-of-block review

Run the weekly review workflow across the complete mesocycle using the raw logs as well as recent summaries. Compare the original success metrics with the baseline and final comparable observations. Separate results, adherence, uncertainty, and preferences.

Review strength/rep performance, relevant body trends if desired, work capacity, symptoms, sleep/recovery, nutrition feasibility, enjoyment, and actual schedule. Do not infer muscle gain from scale weight or diagnose overtraining from a bad week.

Decide whether to repeat, extend, progress, recover, or change the goal/phase. Explain what the previous block taught you, and what evidence justifies the next one. Carry forward effective exercises, meals, and habits; remove friction. Update the user's profile only for user-confirmed factual changes, not inferred traits.

Save the block review, then create the next block and its first detailed microcycle through `plan`. Preserve the macrocycle unless changed circumstances warrant revision. Record assumptions and the next checkpoint; the plan remains revisable.
