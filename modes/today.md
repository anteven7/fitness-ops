# Today's coaching

Resolve today's date in the profile timezone and read the active plan. If there is no plan, onboard/plan. If the plan is expired, the profile has materially changed, or its detailed microcycle has ended, address that before inventing today's scheduled session.

Use the actual calendar, recent completed sessions, and stated readiness. Only ask about sleep, symptoms, soreness, time, or equipment when missing information could change today's action. Avoid a daily interrogation.

Return today's session in order: brief warm-up, exercises with sets/reps/load selection/RIR/rest, alternatives, and time estimate. Show food/meal guidance aligned to the active plan and available ingredients. For limited time, preserve priority work and remove optional accessories. Never cram missed sessions into doubled volume or cut food to compensate for a missed workout.

Acute concerning symptoms override the session. Ordinary fatigue can justify reduced effort or volume; persistent pain needs assessment. Do not diagnose from a readiness score. Record a material schedule change as a versioned adaptation; a one-session adjustment can be noted in context and the eventual workout log. Ask for a compact completion report, without marking the workout done before the user reports it.
